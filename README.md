医学细胞生物学闪卡 —— 使用说明

================================

一、如何打开
双击 index.html，用浏览器（推荐 Edge / Chrome）打开即可使用，无需联网、无需安装。

二、基本操作
· 点击卡片：翻面（正面是概念，背面是解释）
· 上一张：回到看过的上一张卡片
· 下一张：随机抽取一张（默认乱序，不与当前重复）
· 已掌握 / 未掌握：标记当前卡片，再点一次可取消标记；学习进度自动保存在浏览器本地
· 左上角选择框：选择科目和章节（导入新科目后会出现新分组）
· 右上角统计：实时显示总卡片数、已掌握数、未掌握数
· 只看未掌握：只显示未掌握和未学习的卡片
· 只看高频考点：只显示带 🔥 标记的历年高频考点
· 深色模式：点右上角「深色模式」按钮切换，偏好会自动记住

三、快捷键
空格 / 回车：翻面
←：上一张
→：下一张

四、导入新的知识点（TXT）
1. 点击右上角「导入TXT」按钮，选择一个 txt 文件
2. 文件格式：每行一张卡片，用 | 或 ：分隔概念和解释，例如：
   细胞膜|包围在细胞质表面的一层薄膜，由脂双层构成基本结构。
   主动运输：物质逆浓度梯度、从低浓度向高浓度的跨膜转运。
3. 导入后自动生成新科目，可在左上角选择框中切换，刷新后仍然保留

五、修改内置知识点
用记事本（或 VS Code）打开 index.html，找到 SUBJECTS 数组，
按文件中的注释格式直接增删改卡片（front = 概念，back = 解释，hot = true 表示高频考点），
保存后刷新页面即可。

六、常见问题
· 学习进度存在浏览器本地，换电脑或换浏览器后会丢失
· 卡片背面内容较长时可上下滚动查看
· 若导入的 txt 显示乱码，请将文件另存为 UTF-8 编码
